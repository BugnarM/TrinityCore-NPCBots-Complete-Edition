# Azeroth Utility Icons

Add-on pentru WoW 3.3.5a, build 12340. Afișează iconițe native pentru două obiecte Azeroth Reborn în gențile, banca și barele de acțiuni implicite.

- **Junk Scrapper** folosește iconița trusei Gnomish Army Knife.
- **Companion Hearthstone** folosește o rună roșie, diferită de Hearthstone-ul obișnuit.

Copiază folderul `AzerothUtilityIcons` în `World of Warcraft/Interface/AddOns/`, apoi activează-l din meniul **AddOns**. Addonul folosește texturile deja prezente în client. Vânzarea obiectelor prin Junk Scrapper este procesată de server.
